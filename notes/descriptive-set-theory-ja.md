## 0. このノートの読み方

このノートでは，次の順に現行の議論を読む．

1. 任意の位相空間に対する Borel σ-代数の基本性質を確認する．特に，非可分な周囲空間でも使える制限（trace）と引き戻し（pullback）の性質を分けて述べる．
2. `[0,1]` に濃度 `ℵ₁` の稠密な非 Borel 集合 `S` を取る（Prop. 2.1）．
3. `S` を距離の族 `d_t` に符号化し，
   `Φ⁻¹(Met(Z)) = Φ⁻¹(BMet(Z)) = [0,1] \ S`
   という厳密な引き戻しの等式を得る（Lemmas 3.1–3.2）．
4. この等式と，Borel 集合の連続写像による逆像が Borel であるという性質から，距離のモジュライ空間の Borel 性から可分性を導く（Thm. 3.3，Thm. 3.5，Cor. 3.6）．
5. Koshino の定理との関係を確認する．
6. 非アルキメデス的距離への移行を，bi-density の構成と `UMet(Y;R)` の成分の引き戻しによって説明する．
7. 旧 analytic/coanalytic 版がなぜ現行の検証対象ではないかを述べる．

ここで「`M` で Borel」とは，`M` の位相の開集合が生成する Borel σ-代数に属するという意味である．現行の中心的な議論では，`M` がポーランド空間であることを仮定しない．

## 1. Project 標準用語

日本語術語の一覧表は `notes/terminology.md` の「Japanese terminology (both
tracks)」に統合した．本ノートは同表の訳語に従う．特に，perfect set は
**完全集合**（閉かつ孤立点を持たない集合）であり，「完全空間」という語は
完備 (complete) と紛らわしいので使わず，「孤立点を持たない」と明示する．

### 1.1 ポーランド空間

位相空間 `P` が **ポーランド空間 (Polish space)** であるとは，`P` が可分であり，その位相と両立する完備距離が存在することをいう．特定の一つの距離が完備であることだけを意味しない．`[0,1]`，`ℝ`，`2^ω` はポーランド空間である．

### 1.2 analytic と coanalytic の日本語

訳語は `notes/terminology.md` の通り，`analytic set` は **解析集合**，`coanalytic set` は **余解析的集合** である．

これらは記述集合論の標準用語として本ノートの歴史・背景節で使用するが，現行の arXiv:2608.19618 における Borel 版の定理を analytic/coanalytic の定理として読み替えてはならない．

## 2. Borel σ-代数と Borel 集合

### 2.1 定義

位相空間 `M` に対し，`M` の開集合全体を含む最小の σ-代数を `M` の **Borel σ-代数** といい，`ℬ(M)` と書く．`ℬ(M)` の元を **Borel 集合** という．この定義は `M` が可分であることもポーランド空間であることも要求しない．

本ノートの距離空間で用いる標準的な閉包性は次の通りである．

1. 閉集合は Borel 集合である．距離空間ではコンパクト集合も閉集合なので Borel 集合である．
2. Borel 集合は補集合，可算和，可算共通部分で閉じている．したがって，有限個の Borel 集合の共通部分や和集合も Borel 集合である．
3. **制限（trace）:** `B∈ℬ(M)` かつ `L⊆M` ならば，部分空間 `L` において `B∩L∈ℬ(L)` である．これは `M` の開集合の `L` への制限が `L` の開集合であることから，生成元について確認すればよい．
4. **連続写像による引き戻し（pullback）:** `f:N→M` が連続で `B∈ℬ(M)` ならば，`f⁻¹(B)∈ℬ(N)` である．
5. **位相同型による移送:** `h:N→M` が位相同型ならば，`h⁻¹` による Borel 集合の逆像は Borel 集合であり，Borel σ-代数は位相同型で不変である．Borel 同型ではなく位相同型または等長写像を用いる場合は，位相的な逆像と像をそのまま扱ってよい．

4 は以下で用いる性質である．`Φ:P→M` が連続で `M` の部分集合 `A` が Borel ならば，`Φ⁻¹(A)` は `P` で Borel になる．したがって，`Φ⁻¹(A)` が既知の非 Borel 集合であることは，`A` が Borel でないことを示す．

### 2.2 非可分な周囲空間での Borel 性

`CPM(X)` のように非可分な距離空間を周囲空間とする場合も，Borel 性はその距離位相の開集合が生成する σ-代数に関して定義する．現行の証明が使う操作は，上の 1–5 のみである．したがって，周囲空間にポーランド性を仮定する必要はない．

完全集合定理などの完全集合論的な入力は `[0,1]`，`2^ω`，またはそれらに位相同型なコンパクト空間の内部だけで使う．非可分な `CPM(X)` の内部で analytic/coanalytic の点クラスを定義したり，スースリン操作を導入したりする必要はない．

なお，距離空間上の Baire σ-代数や球体 σ-代数を Borel σ-代数より小さい σ-代数として採る流儀を考えても，`σ(open)` に属さないことを示す非 Borel 性は最も強い結論である．

## 3. 距離の空間と周囲空間の規約

以下では `X` を位相空間とする．

### 3.1 `CPM(X)`，`Met(X)`，`BMet(X)`，`Comp(X)`

- `CPM(X)` は，連続な擬距離 `d:X×X→[0,∞)` 全体である．
- `CPM(X)` 上の supremum distance を
  `𝒟_X(d,e)=sup_{(x,y)∈X²}|d(x,y)-e(x,y)|`
  とおく．各 `d,e` の値そのものは有限だが，`𝒟_X` は一般に `[0,∞]` に値を取る．その位相は，通常の距離 `min{𝒟_X,1}` が誘導する位相と同じである．
- `BCPM(X)` は `CPM(X)` の有界な元全体である．
- `Met(X)⊆CPM(X)` は，`X` の位相と両立する距離全体である．ここで「両立する」とは，距離が誘導する位相がもとの `X` の位相と一致することをいう．
- `BMet(X)` は `Met(X)` の有界な元全体である．`Met(X)` 自体には有界性も一様離散性も仮定しない．
- `Comp(X)` は `Met(X)` の完備な元全体である．

### 3.2 有限 sup-distance による成分

`Met(X)` 上で

`d∼e  ⇔  𝒟_X(d,e)<∞`

と定める．`Z` に対して，この同値関係の各同値類を `Met(Z)` の**成分**と呼び，`𝔠` で表す．すなわち

`𝐌_{<∞}(Z)=Met(Z)/∼`．

各成分 `𝔠` は `Met(Z)` で開かつ閉（clopen）であり，弧状連結である．開かつ閉であることは半径 `1` の球体から従い，弧状連結性は両立する距離どうしの凸結合を取ることで得られる．

### 3.3 現行の Borel 証明でポーランド性が不要な理由

現行の周囲空間の規約では，次の四つを明示的に使う．

1. `CPM(X)` の閉集合，およびコンパクト部分集合は Borel 集合である．
2. Borel 集合と閉集合または Borel 集合との共通部分は Borel 集合である．
3. `B` が `M` で Borel で `L⊆M` ならば，`B∩L` は `L` で Borel である．
4. コンパクト空間または閉部分空間への位相同型，等長写像によって Borel 性を移送できる．

完全集合定理が必要になるのはパラメータ空間の `[0,1]` と `2^ω` だけである．したがって，非可分な周囲空間の `CPM(X)` にポーランド構造を仮定することも，analytic/coanalytic の周囲空間の規約を選ぶことも必要ない．

原稿の Theorems 3.3，3.4，3.8 などは `|Z|=ℵ₁` の任意の離散空間 `Z` について述べられるが，符号化は一つの具体的な台集合で行う．二つの離散空間の間の全単射は，両方の引数を付け替える `CPM` の等長写像を誘導し，`Met`，`BMet`，`Comp`，および各成分を保つ．したがって具体的な台集合で得られた主張は，濃度が同じ任意の離散空間へ移る．

## 4. `ℵ₁` と Borel 集合の完全集合定理

### 4.1 濃度の記号

`ℵ₁` は最初の非可算濃度，`ω₁` は最初の非可算順序数，`𝔠` は連続体濃度 `2^{ℵ₀}` とする．

ポーランド空間の非可算 Borel 集合に対しては，次の ZFC の定理を使う．

> **Borel 集合の完全集合定理**（Kechris, Theorem 13.6）．非可算な Borel 集合は空でない完全集合を含み，したがって濃度 `𝔠` を持つ．

ここには CH も `Π¹₁`-PSP も仮定されていない．この ZFC 定理が Prop. 2.1 の基礎である．

### 4.2 ベルンシュタイン集合

空でなく孤立点を持たないポーランド空間 `P` の部分集合 `B` が **ベルンシュタイン集合** であるとは，任意の空でない完全集合 `K⊆P` に対して

`K∩B≠∅` かつ `K\B≠∅`

が成り立つことをいう．したがって `B` も `P\B` も，空でない完全集合を丸ごと含まない．ベルンシュタイン集合は Kechris, Example 8.24 の構成で得られる．

### 4.3 Proposition 2.1

> **Prop. 2.1**（`prop:dense-aleph1-nonborel-interval`，監査 §2.1）．
> `[0,1]` の稠密な部分集合 `S` で，`Card(S)=ℵ₁` かつ `[0,1]` で Borel でないものが存在する．この命題は ZFC で成り立つ．

証明は CH による場合分けである．

- **CH の場合:** `[0,1]` のベルンシュタイン集合を `S` とする．各非空相対開区間は空でない完全集合を含むので `S` は稠密である．また，`S` は `𝔠` 個の互いに素な完全集合と交わるので `|S|=𝔠=ℵ₁` である．もし `S` が Borel なら，非可算 Borel 集合の完全集合定理により，ある空でない完全集合 `K⊆S` を含む．これは `K\S≠∅` に矛盾する．
- **¬CH の場合:** `[0,1]` の可算稠密集合 `Q` を固定し，`Q⊆S⊆[0,1]` かつ `|S|=ℵ₁` となる `S` を取る．`S` は稠密である．また `ℵ₁<𝔠` であるため，`S` が Borel なら非可算 Borel 集合の完全集合定理から `|S|=𝔠` となり，矛盾する．

各分岐で使ったのは ZFC の定理だけである．なお，通常の距離を扱う結果（3.1–3.9）が Prop. 2.1 から使うのは `|S|=ℵ₁` と非 Borel 性であり，`S` の稠密性は非アルキメデス的距離を扱う Lemma 3.11 で使われる．

## 5. カントール空間，Borel 同型，Proposition 2.2

### 5.1 カントール空間

`2={0,1}` を離散空間とし，

`2^ω={t:ω→{0,1}}`

に積位相を入れたものを **カントール空間** と呼ぶ．`2^ω` はコンパクトなポーランド空間であり，空でなく孤立点を持たない．その標準的な非アルキメデス的距離は，非アルキメデス的距離への符号化のパラメータ空間として使われる．

### 5.2 Borel 同型は位相同型ではない

標準 Borel 空間 `X,Y` の全単射 `f:X→Y` が **Borel 同型** であるとは，`f` と `f⁻¹` がともに Borel 可測であることをいう．Borel 同型は Borel 構造を保存するが，開集合，閉集合，稠密性，収束のような位相的性質を一般には保存しない．それらを保存するのは位相同型である．

### 5.3 Proposition 2.2 と稠密性の移送の修正

**v1 の先行ルート（歴史的記録）．**

> **Prop. 2.2**（`prop:dense-aleph1-nonborel-cantor`，監査 §2.2）．
> `2^ω` の稠密な部分集合 `S` で，`Card(S)=ℵ₁` かつ `2^ω` で Borel でないものが存在する．

`[0,1]` と `2^ω` の Borel 同型（Kechris, Theorem 15.6）から非 Borel 性と濃度は移せるが，稠密性は移せない．したがって，Borel 同型だけで Prop. 2.2 を導く議論は不十分である．

修正は次の通りである．Prop. 2.1 の集合を Borel 同型で `2^ω` に移して，非 Borel 集合 `T`，`|T|=ℵ₁` を得る．`2^ω` の可算稠密集合 `Q₀` を取り，`S=T∪Q₀` とする．すると `S` は稠密で `|S|=ℵ₁` である．もし `S` が Borel なら，`Q₀\T` は可算 Borel 集合なので

`T=S\(Q₀\T)`

も Borel となり，`T` の非 Borel 性に矛盾する．これで Prop. 2.2 が得られる．別の方法として，`2^ω` 自体で Prop. 2.1 の CH/¬CH 分岐を実行してもよい．

この v1 の証明は先行ルートとして残すが，以下の強化された bi-density の構成によって置き換えられる．

> **Prop. 2.2（強化形，bi-density）**（`prop:dense-aleph1-nonborel-cantor`，監査 §2.11）．
> `2^ω` の部分集合 `S` で，`Card(S)=ℵ₁`，`S` と `2^ω∖S` の双方が `2^ω` で稠密であり，`S` が `2^ω` で Borel でないものが存在する．

この強化が必要なのは，非アルキメデス的距離への移行で `G=2^ω∖S` を稠密なパラメータ領域として使い，その上の等長写像を `2^ω` 全体へ一意に拡張するためである．v1 の構成は `S` の稠密性だけを保証し，補集合について何も述べなかったため，この役割を果たせなかった．

証明を段階ごとに確認する．

1. `2^ω` の中に互いに素な可算稠密集合 `P,Q` を取る．`2^ω` は完全集合であるポーランド空間なので，二つの集合は可算稠密集合を交互に選ぶ帰納法で構成できる．これは本ノートで既に使っている可算稠密集合の標準的な選択であり，追加の引用を要しない．
2. `2^ω∖P` は可算集合を除いた非可算なポーランド空間，したがって非可算な標準 Borel 空間である．よって Borel 同型
   `f:[0,1]→2^ω∖P`
   が存在する（S. M. Srivastava，*A Course on Borel Sets*，Graduate Texts in Mathematics 180，Springer，Theorem 3.3.13）．
3. Prop. 2.1 が与える集合を `S₀⊆[0,1]` とし，
   `S=f(S₀)∪Q`
   と定める．
4. `Q⊆S` かつ `Q` は稠密なので，`S` は `2^ω` で稠密である．
5. `f` は単射で `Q` は可算だから，
   `Card(S)=Card(f(S₀))=Card(S₀)=ℵ₁`
   である．
6. `f(S₀)⊆2^ω∖P` であり，`P∩Q=∅` なので，`P⊆2^ω∖S` である．`P` は稠密だから，`2^ω∖S` も稠密である．
7. `S` が Borel だと仮定する．このとき `S∖Q` は Borel であり，`S∖Q=f(S₀)∖Q` である．したがって，
   `f(S₀)=(S∖Q)∪(f(S₀)∩Q)`
   であり，右辺の第二項は可算 Borel であるから `f(S₀)` も Borel である．一方，`P` は可算なので `2^ω∖P` は `2^ω` で Borel であり，`f` はそこへの Borel 同型である．したがって `f(S₀)` が Borel ならば，Borel 構造を `f⁻¹` で引き戻して `S₀` が `[0,1]` で Borel となる．これは Prop. 2.1 に矛盾する．ゆえに `S` は Borel ではない．

ここで `f` は Borel 構造と濃度の移送だけに使い，稠密性その他の位相的性質の移送には使っていない．`S` の稠密性と `2^ω∖S` の稠密性は，`2^ω` 自体で選んだ互いに素な可算稠密集合 `P,Q` から直接得ている．これは §5.2 の「Borel 同型は位相同型ではない」という一般事実を正しく適用したものである．v1 の欠陥は `S=f(S₀)`（旧記法の `T`）そのものの稠密性を必要とした点にあり，Borel 同型はそれを保証しない．新しい証明は `f(S₀)` 単独の稠密性を一度も要求せず，Borel 同型で保存される非 Borel 性と濃度だけを移送し，`P,Q` によって稠密性と余稠密性を別に構成している．

以上が，v1 の証明を先行ルートとして可視化したまま，現在の bi-density construction に置き換える修正である．

## 6. 距離の符号化と厳密な引き戻し

ここからは Prop. 2.1 の集合 `S` を一つ固定する．その単射な列挙を

`S={w_α:α<ω₁}`

とし，離散空間

`Z={p,q}⊔{b_α:α<ω₁}⊔{c_{α,n}:α<ω₁,n∈ℤ_{≥0}}`

を考える．`C_α={b_α}⊔{c_{α,n}:n∈ℤ_{≥0}}` とおく．`|Z|=ℵ₁` である．

### 6.1 Lemma 3.1

`t∈[0,1]` に対し，

`l_n(α,t)=|t-w_α|+2^{-n}`

と定める．`d_t` を対称に定め，異なる点について

`d_t(p,q)=1+t`，

`d_t(b_α,c_{α,n})=l_n(α,t)`，

`d_t(c_{α,n},c_{α,m})=l_n(α,t)+l_m(α,t)`（`n≠m`），

分割 `{p,q}∪{C_α:α<ω₁}` の異なる二つの部分に属する二点について

`d_t(u,v)=4`

とする．対角上では `d_t(u,u)=0` とする．

> **Lemma 3.1**（`lem:metric-coding`，監査 §2.4）．
> 任意の `t∈[0,1]` に対し，`d_t` は `Z` を台集合とする有界距離であり，
> `d_t∈Met(Z)  ⇔  t∈[0,1]\S`
> が成り立つ．

`d_t` の各値は `[0,4]` に入る．`t=w_β∈S` のときも `d_t` は距離であるが，`d_t(b_β,c_{β,n})=2^{-n}→0` なので `b_β` が孤立しない．反対に `t∉S` なら，`p,q` と各 `c_{α,n}` には正の孤立半径があり，`b_α` では

`inf_n l_n(α,t)=|t-w_α|>0`

である．したがって `d_t` が誘導する位相は `Z` の離散位相と両立する．

### 6.2 Lemma 3.2 と引き戻しの等式

`Φ:[0,1]→CPM(Z)` を `Φ(t)=d_t` で定める．

> **Lemma 3.2**（`lem:closed-parameter-embedding`，監査 §2.5）．
> `Φ` は双 Lipschitz な埋め込みであり，`Φ([0,1]\S)` は `Met(Z)` で閉集合である．具体的に，
> `|s-t| ≤ 𝒟_Z(d_s,d_t) ≤ 2|s-t|`
> が成り立つ．

下側の評価は `(p,q)` での値から得られ，上側の評価は `d_t` の定義に現れる各値の `t` に関する Lipschitz 性から得られる．閉集合であることは，`d_{t_k}→d∈Met(Z)` ならば `(p,q)` での値から `t_k→t=d(p,q)-1` が分かり，極限が `d_t` であることと Lemma 3.1 から `t∉S` が従うことによる．

`L=Φ([0,1])` とおくと，`L` はコンパクトであり，したがって `CPM(Z)` で閉かつ Borel である．Lemma 3.1 の意味は，次の厳密な引き戻しの等式にまとめられる．

`Φ⁻¹(Met(Z)) = Φ⁻¹(BMet(Z)) = [0,1]\S`．

同値に，

`L∩Met(Z) = L∩BMet(Z) = Φ([0,1]\S)`

である．この等式が，距離のモジュライ空間の Borel 性をパラメータ空間上の Borel 性に引き戻す．

## 7. Borel 性から可分性へ

### 7.1 Theorem 3.3

> **Theorem 3.3**（`thm:bounded-discrete-nonborel`，監査 §2.6）．
> `Z` が離散空間で `|Z|=ℵ₁` ならば，`BMet(Z)` は `CPM(Z)` で Borel ではない．

実際，`BMet(Z)` が `CPM(Z)` で Borel だと仮定すると，`Φ` の連続性と §2 の「連続写像による逆像は Borel」という性質により

`Φ⁻¹(BMet(Z))=[0,1]\S`

が `[0,1]` で Borel になる．補集合を取れば `S` も Borel となり，Prop. 2.1 に矛盾する．ここでは `CPM(Z)` がポーランド空間であることを使っていない．`L` への制限と `L≅[0,1]` による移送を使う証明も同じ議論であり，§2.2–§3.3 の周囲空間の規約の具体例である．

**Met と BMet の記述上の注意:** 原稿の要旨と序論はこの結果を，時に `Met(Z)` is not Borel と述べるが，本文の Theorem 3.3 は `BMet(Z)` の形で書かれている．同じ厳密な引き戻しの等式から `Met(Z)` 版も成り立つ．この二つを同一の主張として扱うのではなく，本文の BMet 版と，要旨・序論の Met 版を区別して読む．

### 7.2 外部定理 E1（距離の拡張作用素）

Theorem 3.5 では，Ishiki による距離の拡張作用素（extensor）の定理を，証明の明示的な外部入力として使う．

> **E1**（Ishiki，*An isometric extensor of metrics*，arXiv:2407.03030 v4，Theorem 1.1）．`X` が距離化可能な空間，`A` が `X` の閉部分集合ならば，写像 `E:Met(A)→Met(X)` で次を満たすものが存在する．
>
> (1) `E(d)|_{A²}=d` for every `d∈Met(A)`．
>
> (2) `E` は等長埋め込みであり，`𝒟_A(d,e)=𝒟_X(E(d),E(e))`．
>
> (3) `E(BMet(A))⊆BMet(X)`．
>
> (4) `E(Comp(A))⊆Comp(X)`．
>
> さらに，擬距離に対する拡張作用素 `Ẽ:CPM(A)→CPM(X)` が存在し，`Ẽ|_{Met(A)}=E`，`Ẽ(Met(A))=Ẽ(CPM(A))∩Met(X)` であり，`E(Met(A))` は `Met(X)` で閉集合である．

ここで項目 (4) は，`X` が完備距離化可能である場合に使う．E1 の原論文の項目 (4) は無条件の形で書かれているが，その証明と現行の使用箇所では `X` の完備距離化可能性が必要である．Theorem 3.5 では項目 (1)，(2) と擬距離レベルの拡張作用素を使う．

### 7.3 Theorem 3.5

> **Theorem 3.5**（`thm:borel-separability`，監査 §2.8）．
> `X` が距離化可能で，`Met(X)` が `CPM(X)` で Borel ならば，`X` は可分である．

証明の構造は対偶である．`X` が非可分ならば，`X` は `|Z|=ℵ₁` の ε-分離な閉離散部分空間 `Z` を含む．E1 の `Ẽ:CPM(Z)→CPM(X)` は等長写像で，その像は `CPM(X)` で閉じている．また

`E(Met(Z)) = Ẽ(CPM(Z)) ∩ Met(X)`

が成り立つ．したがって，`Met(X)` の Borel 性を閉じた像へ制限し，`Ẽ` の像の上の位相同型で引き戻せば，`Met(Z)` の Borel 性，または各成分 `𝔠` の Borel 性が得られる．これは Theorem 3.3 の `Met(Z)` 版，または Theorem 3.4 の成分版に矛盾する．

この証明で使う記述集合論的な操作は，閉集合，制限，位相同型による移送だけである．`CPM(X)` のポーランド性は不要である．なお，成分を経由しない `Met(Z)` 版の引き戻しを使えば Theorem 3.5 の最小の証明の連鎖が得られ，Theorem 3.4 は独立に再利用できるより精密な結果として残る．

### 7.4 Alexandrov–Lavrentiev と Corollary 3.6

次の Alexandrov–Lavrentiev の `G_δ` による特徴づけを使う．

> `X` が距離化可能で `Y⊆X` が完備距離化可能ならば，`Y` は `X` で `G_δ` である．

これは周囲空間 `X` の可分性を要求しない（Kechris, Theorem 3.11）．逆向きの「`G_δ` なら完備距離化可能」はここでは使わない．

> **Corollary 3.6**（`cor:metric-space-complete-separability`，監査 §2.9）．
> `X` が距離化可能で，`Met(X)` が完備距離化可能ならば，`X` は可分である．

`Met(X)` は `CPM(X)` の距離化可能な部分空間なので，Alexandrov–Lavrentiev により `CPM(X)` で `G_δ`，したがって Borel である．Theorem 3.5 を適用すれば結論を得る．この Corollary 3.6 が，Conjecture 5.1 を強化された Borel の形で解決する系である．

## 8. Koshino の定理との関係

### 8.1 Corollary 3.7

> **Corollary 3.7**（`cor:bounded-metric-complete-sigma-compact`，監査 §2.10）．
> `X` が距離化可能ならば，
> `BMet(X)` が完備距離化可能であることと，`X` が σ-コンパクトであることは同値である．

Koshino の結果を適用するには `X` の可分性が必要である．Corollary 3.6 は `Met(X)` の完備距離化可能性から可分性を出すが，`BMet(X)` の完備距離化可能性は直接扱わない．したがって，`BMet` について Theorem 3.5 と同じ拡張作用素による引き戻しを一度行う．すなわち，非可分な `X` から得た閉離散集合 `Z` に対し，E1 の項目 (3) により `E(BMet(Z))⊆BMet(X)` となるが，包含だけでは `BMet(X)` の Borel 性を `BMet(Z)` へ引き戻すのに不十分である．`Ẽ` による像 `Ẽ(CPM(Z))` への制限がちょうど `BMet(Z)` と一致することを別に確かめる必要があり，有界な距離の制限は有界であることから

`E(BMet(Z)) = Ẽ(CPM(Z)) ∩ BMet(X)`

という厳密な等式が成り立つ．したがって，`BMet(X)` が `CPM(X)` で Borel なら，この等式と §2 の制限の性質により `E(BMet(Z))` は `Ẽ(CPM(Z))` で Borel であり，位相同型 `Ẽ` で引き戻せば `BMet(Z)` は `CPM(Z)` で Borel になる．`BMet(X)` が完備距離化可能なら Alexandrov–Lavrentiev によりこの意味で Borel であり，この引き戻しは Theorem 3.3 に矛盾する．よって `BMet(X)` が完備距離化可能なら `X` は可分である．

ここで使う Koshino の外部定理は次である．

> **E3**（Koshino，*On the Borel complexity and the complete metrizability of spaces of metrics*, Anal. Geom. Metr. Spaces 12 (2024)）．
> `X` が可分距離化可能ならば，`X` が σ-コンパクトであることと，`AM(X)=BMet(X)` が完備距離化可能であることは同値である．

σ-コンパクトな距離化可能空間ならば E3 により `BMet(X)` は完備距離化可能である．逆に，`BMet(X)` が完備距離化可能ならば，上の `BMet` 版の引き戻し，Alexandrov–Lavrentiev，Theorem 3.3 によりまず `X` の可分性を得てから E3 を適用する．

### 8.2 `AM(X)` と `Met(X)` の注意

Koshino の `AM(X)` は有界な許容距離（admissible metric）全体の空間であり，現行の記号では `BMet(X)` と同一視する．これは `Met(X)` と同じものではない．`Met(X)` は有界とは限らない両立する距離も含み，`BMet(X)` はその有界な部分空間である．したがって，Koshino の定理を `Met(X)` の定理として記憶してはならない．

原稿の引用には Koshino の `Corollary 1.2` という番号が現れるが，確認された出版版の本文では主定理と系は無番号である．最終的な引用では出版版の番号と書誌情報を照合する．

## 9. 「Borel ⇒ 可分性」の構造

現行の中心的な結果の流れは次の通りである．

~~~text
Prop. 2.1
  ↓  S ⊆ [0,1]，|S|=ℵ₁，S は稠密かつ非 Borel
Lemmas 3.1–3.2
  ↓  t ↦ d_t，Φ⁻¹(Met(Z)) = Φ⁻¹(BMet(Z)) = [0,1]\S
Theorem 3.3
  ↓  |Z|=ℵ₁ の離散 Z では BMet(Z) は CPM(Z) で非 Borel
E1（拡張作用素）+ 閉離散部分空間 + 周囲空間での引き戻し
  ↓
Theorem 3.5
  ↓  Met(X) が CPM(X) で Borel なら X は可分
Alexandrov–Lavrentiev の Gδ による特徴づけ
  ↓
Corollary 3.6
  ↓  Met(X) が完備距離化可能なら X は可分
~~~

非可分な距離化可能空間 `X` は濃度 `ℵ₁` の閉離散部分空間 `Z` を含む．E1 は `Z` 上の擬距離と距離を `X` 上へ等長的に移す．そのため，もし `Met(X)` が Borel なら，`Z` 上の距離のモジュライ空間も Borel になる．しかし Lemmas 3.1–3.2 が与える具体的な非 Borel 集合 `[0,1]\S` はそれを禁じる．したがって，距離のモジュライ空間の Borel 性は可分性の必要条件である．

この議論では，非 Borel なパラメータ集合を連続写像によって Borel 集合の逆像として得る．Borel σ-代数の定義域である周囲空間が非可分でも，制限と連続写像による引き戻しはそのまま成立する．これが旧 analytic/coanalytic の定式化を Borel の定式化に置き換える理由である．

## 10. 非アルキメデス的距離への移行

以下では，`Y` を非可分な超距離化可能空間，`R` を characteristic な range set とする．すなわち，`0` は `R∖{0}` の集積点である．`UMet(Y;R)` は `Y` と両立する `R`-値超距離全体，`UCPM(Y;R)` は `Y` 上の連続な `R`-値擬超距離全体である．`R`-components `𝔠^R` は，
`𝒰𝒟^R_Y(d,e)<∞`
で定める同値関係の同値類である．

> **Corollary**（`cor:nonseparable-ultrametric-nonborel`，監査 §2.19）．
> `Y` が非可分な超距離化可能空間ならば，`UMet(Y;R)` のすべての `R`-component `𝔠^R` は `UCPM(Y;R)` で Borel ではない．したがって `UMet(Y;R)` 自体も `UCPM(Y;R)` で Borel ではない．

v1 の経路が失敗した理由は，超距離版の extensor である Ishiki の因数分解定理（プロジェクトのラベル E2）が `UCPM` レベルの extensor を供給せず，`UMet` から `UMet` への等長埋込みだけを供給する点にある．そのため，Archimedean の場合のように，擬距離レベルの extensor に沿って周囲空間の Borel 構造を引き戻す戦略は直接には移せない．

新しい経路を段階ごとに確認する．

1. `R`-component `𝔠^R` と `d∈𝔠^R` を固定する．`(Y,d)` は非可分なので，ある `ε>0` に対して可算 `ε`-ネットが存在しない．`R` が characteristic なので，`a∈R∖{0}` を `a≤ε` となるように取れる．`A` を `Y` の maximal a-separated subset とする．超距離空間では，`A` の点を中心とする開 `a`-球は `Y` の開かつ閉な集合からなる分割（clopen partition）をなす．その各球の中心を送る写像
   `π:Y→A`
   は連続な retraction であり，すべての `x∈Y` に対して `d(x,π(x))<a` を満たす．`A` は `a`-ネットである．もし `A` が可算なら，`a≤ε` から可算 `ε`-ネットが得られ，仮定に矛盾する．したがって `A` は非可算であり，閉かつ離散である．
2. `A` を一つの点に潰し，`Y` を `A` と各一点集合 `\{x\}`（`x∈Y∖A`）からなる分割で割った商を考える．これは 0 次元の距離化可能空間になる．`R` が characteristic なので，この商には両立する `R`-値超距離 `v₀` があり，`b∈R∖{0}` に対して
   `v=min(v₀,b)`
   と切り詰めても，`v` は両立する `R`-値超距離で `v≤b` を満たす．これは因数分解論文の構成データ（プロジェクトのラベルでは E2c）であり，その論文の内部構成をここで再現するものではない．
3. 同じ因数分解論文の extensor construction をこの retraction `π` に特殊化する（E2/E2c）．構成の companion projection を `p` と書くと，`A` 上の `R`-値超距離 `w` に対して，等長埋込み型の extension operator `E` は
   `E(w)(x,y)=w(π(x),π(y))∨v(p(x),p(y))`
   という max-form を持つ．また，`E(w)|_{A×A}=w` である．ここで E2/E2c は，この形を使うための外部入力として扱う．
4. `d` の `A×A` への制限に `E` を適用して
   `d̂=E(d|_{A×A})`
   とする．`d(x,π(x))<a`，`v≤b` および構成の max-form から，`τ=a∨b` とおけば強三角不等式を `π(x),π(y)` を経由して適用して
   `d̂(x,y)≤d(x,y)∨τ`，`d(x,y)≤d̂(x,y)∨τ`
   を得る．したがって `𝒰𝒟^R_Y(d̂,d)≤τ<∞` であり，`d̂∈𝔠^R` である．つまり，`d` 自身の制限に extension operator を適用した基準拡張は，`d` と同じ `R`-component に留まる．
5. このプロジェクトで既に使っている離散超距離符号化，すなわち Lemmas 3.10–3.11 の Z-coding の超距離版を，`Y` 全体ではなく `A` の内部で実行する．`z∈A` を固定する．`R` の可算共終部分集合を使うと `A` は `z` を中心とする閉 `d|_{A×A}`-球の可算和になるので，その一つの球 `B` は非可算である．`H⊆B` を `z∈H` かつ `Card(H)=ℵ₁` を満たすように取り，Z-coding を `H` に `y₀↦z` として移し，`(A∖H)∪\{z\}` 上の `d|_{A×A}` と max 形式で貼り合わせて，`t∈2^ω` でパラメータ付けられた `A` 上の `R`-値超距離の族 `m_t` を得る．`m_t` は `t∉S` のときに限って `A` と両立する．次の三つの評価が成り立つ．`A` は `a`-分離集合なので，`t∉S` のとき `A∖H` の各点は半径 `a` で孤立し，`H` の中心以外の各点は符号化の半径で孤立し，交差距離は `e_t(z,u)>0` または `d(x,z)≥a` で下から抑えられる（`t∈S` のときは `H` 内の符号化の中心が孤立しない）．また `𝒰𝒟^R_A(m_t,d|_{A×A})≤γ`（`γ=q∨r(0)`）であり，等長性の評価は `H` 内の分離対から従う．
6. `F:G→UCPM(Y;R)` を `t∈G=2^ω∖S` に対して `F(t):=E(m_t)` で定める．`t∈G` では `m_t∈UMet(A;R)` なので `E(m_t)` が定義される点に注意する（`t∈S` では `m_t` が `A` と両立しないため `E(m_t)` 自体が定義されない）．手順 3 の `E` の等長性と手順 5 の等長性の評価から，`F` は `G` 上で等長写像である．`G` が稠密なのは，Prop. 2.2 の強化形で `S` とその補集合の双方が稠密だからである．`UCPM(Y;R)` が完全距離化可能であるという標準事実を使うと，この稠密な `G` 上の等長写像 `F` は，`2^ω` 全体から `UCPM(Y;R)` への一意な連続写像
   `F̄:2^ω→UCPM(Y;R)`
   に一意に拡張される．`t∈S` における `F̄(t)` は `E(m_t)` を評価したものではなく，稠密な `G` 上の値からの連続極限として定まる．
7. 制限写像と `t↦m_t` は連続であり，`F̄` と `t↦m_t` が稠密な `G` 上で一致するので，
   `F̄(t)|_{A×A}=m_t`
   はすべての `t∈2^ω` で成り立つ．`t∈G` の場合，手順 4 の評価 `𝒰𝒟^R_Y(d̂,d)≤τ` と手順 5 の評価 `𝒰𝒟^R_A(m_t,d|_{A×A})≤γ` を，`E` の等長性を用いて強三角不等式で合成すると
   `𝒰𝒟^R_Y(F̄(t),d)≤γ∨τ`
   が得られるので，`F̄(t)∈𝔠^R` である．`t∈S` の場合，制限 `F̄(t)|_{A×A}=m_t` が `A` の位相と両立しない．`A` は `Y` の閉集合であり，`Y` と両立する超距離を `A` に制限すれば `A` の部分空間位相と両立するはずだから，この不整合により `F̄(t)` 自身は `Y` と両立する超距離になり得ず，特に `F̄(t)∉𝔠^R` である．ゆえに
   `F̄⁻¹(𝔠^R)=G`
   である．`G` は非 Borel である．実際，Prop. 2.2 により `S` が非 Borel であり，Borel 集合の補集合は Borel なので，`G=2^ω∖S` も非 Borel である．§2 の項目 4「連続写像による引き戻し」によれば，`𝔠^R` が `UCPM(Y;R)` で Borel なら `G` は `2^ω` で Borel になるため，`𝔠^R` は `UCPM(Y;R)` で Borel ではない．さらに `R`-components は `UMet(Y;R)` で開かつ閉なので，もし `UMet(Y;R)` 自体が `UCPM(Y;R)` で Borel なら，その中の `𝔠^R` も相対開集合として Borel になり，矛盾する．したがって `UMet(Y;R)` も Borel ではない．

この経路の要点は，`F` を定義する `G` が稠密であることである．そのため，Prop. 2.2 の強化形の余稠密性は単なる付加条件ではなく，`UCPM(Y;R)` の完全性を使って `2^ω` 全体へ一意に拡張するための入力である．また，この証明は E2 の `UCPM` レベル extensor を必要としない．

**Lean 形式化の状況．** `thm:ultrametric-borel-separability` 型および `cor:complete-ultrametric-borel-separability` 型の主張に対する Lean 開発の既存の経路は，`Ext/UltraTransfer.lean` と `Ext/UltraCompleteTransfer.lean` にある．これは `2^ω∖S` の閉包を完全な周囲空間の中で用いる密な一様拡張によるもので，本節で述べた経路とは独立に，以前から検証済みの経路である．この Lean の経路は同じ定理主張に対する健全で検証済みの代替ルートであり，本節の新しい経路に置き換えられたものでも，時代遅れとして扱うものでもない．本節で述べた，密な全カントール空間への拡張による経路の Lean 形式化は本ノート執筆時点で完了しておらず，本ノートはその完成を主張しない．新しい経路へ書き換えるか，既存の閉包に基づく証明を検証済みの代替として維持するかは GitHub の Issue #110 で追跡されている未解決の判断であり，Issue #110 は本ノート執筆時点で未解決のままである．

## 11. 歴史・背景：解析集合・余解析的集合版で残ることと残らないこと

この節の内容は記述集合論の背景であり，arXiv:2608.19618 の現行の検証対象ではない．

### 11.1 古典的な点クラスの関係

ポーランド空間である周囲空間 `P` では，解析集合 `Σ¹₁` はポーランド空間からの連続写像の像として表される集合，余解析的集合 `Π¹₁` は補集合が解析集合である集合である．Borel 集合は解析集合かつ余解析的集合であり，Souslin の定理により

`analytic ∩ coanalytic = Borel`

が成り立つ．したがって

`neither analytic nor coanalytic ⇒ non-Borel`

であるが，`non-Borel ⇒ neither analytic nor coanalytic` ではない．

### 11.2 旧レシピの「解析集合でない」は何が残るか

Prop. 2.1 の CH 分岐で選ぶベルンシュタイン集合は非可算で完全集合を含まないので，解析集合の完全集合性から解析集合ではない．¬CH 分岐では `|S|=ℵ₁<𝔠` であるため，解析集合の完全集合定理から解析集合ではない．したがって，旧 CH/¬CH のレシピから得られる「`S` は解析集合でない」という半分は ZFC で保たれる．

### 11.3 「余解析的集合でない」は ZFC の定理ではない

一方，旧 draft が主張した「密な `S⊆[0,1]`，`|S|=ℵ₁` は余解析的集合でもない」という半分は ZFC の定理ではない．

ZFC + ¬CH のモデルとして，`ω₁^L=ω₁` を保つ `L` の ccc な強制拡大，例えば `L` に `ℵ₂` 個の Cohen 実数を加えたモデルを考える．そのようなモデルでは，最大の thin `Π¹₁` 集合 `C₁` が存在し，`C₁` は濃度 `ℵ₁` の稠密な余解析的集合である（Kechris 1975，Guaspari 1973，Sacks 1976）．旧 CH/¬CH のレシピは，可算稠密集合 `Q` を固定して `Q⊆S` かつ `|S|=ℵ₁` となる稠密な `S` を選ぶ手続きであり，`Q` は `C₁` の中に取れる．したがって `C₁` はこのレシピが許す正当な出力の一つであり，その出力は余解析的集合になる．

ここでは，証明可能性 (provability) と相対無矛盾性 (relative consistency) を区別する．一つの ZFC + ¬CH モデルでこの主張が失敗することを示せば，「この主張は ZFC の定理である」という主張を反証できる．これは，否定命題の相対無矛盾性を一般に確立することとは異なる，より弱い事実である．CH が成り立つモデルで旧レシピがどう振る舞うかを決めることも，この ZFC における証明可能性の反証には必要ない．

ZFC で安全な修正には Mansfield–Solovay の定理が関係する．この定理は，`Σ¹₂(a)` 集合が `L[a]` に含まれるか，または完全部分集合を含むことを述べる．したがって，`S` が余解析的集合でないことをこの方向から保証するには，すべての実数 `a` に対して `S⊄L[a]` となる構成が必要になる．旧レシピはこの条件を ZFC で供給しない．

### 11.4 なぜ Borel で十分か

古典的な analytic/coanalytic の関係はポーランドな周囲空間で有効であるが，非可分な `CPM(X)` にそのまま適用するには点クラスの規約が必要になる．旧 draft ではこの周囲空間の問題のため，非可分な周囲空間に対する analytic/coanalytic の主張が定義に依存し，`BMet(D)` やその補集合の稠密性のため古典的な点クラスの読み方では定理が空虚になる場合があった．

現行の Borel の定式化では，Borel σ-代数を周囲空間の位相から直接定義する．Borel 集合に対する完全集合定理は ZFC の定理であり，thin な Borel 集合の問題は生じない．また，非可分な周囲空間にポーランド性を仮定せず，スースリン操作や analytic/coanalytic の点クラスの規約も導入しない．このため，Prop. 2.1 と Lemmas 3.1–3.2 の厳密な引き戻しが，Theorem 3.3 から Theorem 3.5，Corollary 3.6 へ直接つながる．
